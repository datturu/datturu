## Featured Research

### [Deep Learning in Archiving Indus Script and Motif Information](https://journal.caa-international.org/articles/10.5334/jcaa.175)

*Journal of Computer Applications in Archaeology*, 2025 · Peer reviewed · V. Dixit, N. Hussain, S. Basak, **D. Atturu**, D. Mitra, U. Bhattacharya

An end-to-end pipeline that reads the undeciphered Indus Valley script from 4,000-year-old seals: **YOLOv3** finds each sign, **MobileNet** identifies it (**94.5% accuracy**, best of 15 models tested), a custom CNN identifies the seal's motif, and everything is archived in a searchable database. I ran the initial experiments and built the database and the end-to-end workflow.
